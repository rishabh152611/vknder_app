# vknder — Social Event & Meetup Platform

A sleek, real-time mobile app built with Flutter to empower users in creating, discovering, and joining events seamlessly. vknder focuses on campus communities, clubs, and local meetups, providing intuitive tools for event management and social interaction.

## 🚀 Features

- **Event Creation & Discovery**: Easily create events with details like date, location, and capacity; browse with live search and filters for quick results under 100ms.
- **Real-Time Chat**: Join group discussions for each event using Firebase Realtime Database for instant, zero-downtime messaging.
- **Secure Authentication**: OTP-based login via Firebase Auth for fast and secure user onboarding.
- **Engaging UI/UX**: Dynamic animations with Lottie, responsive designs, and customizable themes to enhance user experience.
- **Scalability & Performance**: Handles 100+ active users with modular architecture and efficient state management.

## 🛠️ Tech Stack

- **Frontend**: Flutter, Dart
- **Backend**: Firebase (Auth, Realtime Database)
- **State Management**: Provider, Bloc
- **APIs & Integrations**: REST APIs, Google Maps (for location-based events)
- **Animations**: Lottie
- **Dev Tools**: Git, GitHub Actions for CI/CD
